# 미확정 항목

결정되면 해당 본문 문서로 옮기고 여기서 지운다.
각 항목은 본문의 ❓ 마커와 대응한다.

## 홈 화면 — [04-gui-spec.md §2](04-gui-spec.md#2-홈진입-화면)

- [ ] **화면 이름과 파일명의 관계** — `screen.name`과 `.visual-spec/specs/*.json` 파일명을 동기화할지, 독립적으로 둘지. 동기화하면 이름 변경 시 파일도 옮겨야 하고, 독립이면 목록에서 파일을 특정하기 어려워진다
- [ ] **목록 항목의 액션 범위** — 열기 외에 복제 · 삭제 · 이름 변경 중 무엇을 MVP에 넣을지
- [ ] **프로젝트 개념의 존재 여부** — 화면만 나열할지, 화면을 묶는 상위 단위를 둘지. 현재 명세는 화면만 나열하는 전제다

## 에디터 — [04-gui-spec.md](04-gui-spec.md)

- [ ] **Version History와 Undo의 관계** — 별개 기능인지, File 메뉴에 넣을지. MVP 제외 가능성 있음 (§4.1)
- [ ] **새 레이어 명명 규칙 및 선택 카드 UI** (§6)
- [ ] **도구 선택 후 Esc 동작** — Select 도구로 자동 복귀할지 (§8)
- [ ] **Frame 도구의 기본 스타일** — 배경색·radius가 기본으로 적용되는지 (§8)
- [ ] **Shape 도구의 기본 도형 처리 방식** — 기본 도형 제공 도구인지, 공용 컴포넌트로 처리할지 (§8)
- [ ] **캔버스 드래그 생성 시 root 트리 자동 추가 로직** (§8)
