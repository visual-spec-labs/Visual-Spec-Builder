# 2026-10-19 #443 모호한 자연어 요청 — 실제 모델 재실행 기록

#431 고객 B 시나리오("좀 더 예쁘게"에 명령 18개가 바로 적용되고 Card 간격 24가 16으로 바뀜)를
`skills/visual-spec-nl-response/SKILL.md`의 "모호한 요청" 절을 추가한 뒤 실제 모델로 다시 돌렸다.

## 환경

- 저장소: `docs/443-nl-ambiguous-request` 브랜치(develop `8b51528` 기반 + 스킬 변경), macOS, Chromium(Playwright 1.61.1)
- 에이전트: Claude Code 2.1.303 `claude -p`, 모델 `claude-opus-5-5`(실행 로그의 `models`). 모델 인자는 지정하지 않았다.
- 도구: `scripts/browser/real-model-journey.mjs`의 `setup` → `nl` 단계. GUI가 보여 주는 지시문을 그대로 에이전트에 넘겼고,
  응답 파일은 모델이 썼다. QA 도구는 응답을 쓰거나 고치지 않는다.
- 시작 상태: `examples/login-screen.json`을 작업공간 `specs/login-screen.json`으로 복사하고 Card의 `layout.gap`을
  24로 바꿨다. 고객이 앞 단계에서 "간격을 24로 바꿔줘"로 만든 상태와 같다(이 단계는 모델로 다시 돌리지 않았다).
  적용 범위는 세 번 모두 **현재 화면**이다.

  명령이 하나도 오지 않았다.
- 실행 2는 대상(버튼·카드)이 정해진 요청이라 모델이 되묻지 않고 두 노드의 모양 속성만 바꿨다. 모델 요약에도 "`gap: 24`, `padding`,
  크기, 텍스트 내용은 요청에 없었으므로 그대로 두었습니다"라고 적혔다. 배경 종류가 바뀌어 GUI가 적용 전 확인을 띄웠고, 여정 도구는
  확인을 자동 승인하지 않으므로 적용 단계는 실행하지 않았다. 보존 판정은 응답 Command 목록으로 했다.

## 한계

- 표본은 한 모델로 세 번이다. 에이전트 판단이라 다른 모델·다른 문구에서는 다르게 나올 수 있다.
- 두 번의 되묻기 모두 제안 3개 중 2개가 SKILL.md 예시('로그인 버튼 모서리를 12로 둥글게', '제목 글자 크기를 28로')와
  속성·값이 같았다. 모델은 "예시는 실제 노드 이름으로" 규칙대로 이름만 `LoginButton`·`Title`로 바꿨다. 나머지 하나는
  예시('Card에 옅은 그림자 추가')와 달랐다('Card에 흰 배경과 옅은 테두리', 'Card 배경을 흰색으로'). 그대로 보낼 수 있는
  요청이지만, 화면에 맞춘 제안이라기보다 예시를 옮긴 것에 가깝다.
- 되묻기는 `error` 응답이라 GUI에서 오류 색으로 보인다. 되묻기 전용 표시는 이번 범위에 넣지 않았다.
- 멀티턴 맥락이 없어 "직전 요청에서 정한 값"을 따로 알 수 없다. 요청이 말하지 않은 값을 모두 유지하는 방식으로 지킨다.
